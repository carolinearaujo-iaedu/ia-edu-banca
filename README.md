# Rubrica de avaliação · Bancas da D6

Ferramenta de preenchimento da rubrica das bancas da D6 (Projeto Aplicado em Políticas Públicas com IA) da Especialização em IA para Políticas Públicas em Educação e Cultura · IA.Edu · UFAL · Fundação Itaú.

- Página única (`index.html`), sem dependências externas: fontes, logos e gerador de PDF vão embutidos.
- O preenchimento fica salvo no navegador de quem avalia; nada é enviado a servidor.
- Gera o PDF da Parte 1 e o PDF final de cada GT, com as notas gravadas no próprio PDF.
- Exportar/Importar preenchimento (.json) para não depender da memória do navegador.

Publicado pelo GitHub Pages a partir da branch `main`, pasta raiz.
